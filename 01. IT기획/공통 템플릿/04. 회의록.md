## 이 문서는

회의에서 **무엇을 논의했고, 무엇을 결정했고, 누가 무엇을 언제까지 할지** 를 한 장에 남기는 기록.

회의록의 진짜 목적은 "회의 내용 받아쓰기"가 아니라 **합의된 결정과 액션 아이템을 명확히 남기는 것**. 잘 쓴 회의록은 그 자리에 없던 사람도 5분 안에 따라잡을 수 있다.

## 언제 만드나

회의 시작 전에 빈 양식을 미리 띄워두고, **회의 중 실시간으로 기록**. 회의 종료 후 24시간 안에 정리해서 공유.

## 어떤 툴로

| 툴         | 추천도  | 이유                                          |
| --------- | ---- | ------------------------------------------- |
| **노션**    | ⭐ 추천 | 실시간 동시 편집, 페이지·DB로 누적 관리, 액션 아이템 체크박스 자연스러움 |
| 구글 독스     | 추천   | 동시 편집·코멘트 협업 강점                             |
| Slack 스레드 | 보조   | 짧은 회의·결정사항만 남길 때                            |
| 이메일       | 보조   | 외부 고객사와의 공식 회의 후 confirmation 용도            |

**팁**: 노션에 "회의록" 데이터베이스를 하나 만들고 회의마다 새 페이지로 추가하면 누적 관리 편함.

## 들어가야 할 것

핵심 4가지만 잘 챙기면 된다.

|항목|설명|
|---|---|
|메타정보|일시, 장소, 참석자, 작성자|
|안건|회의에서 다룰 주제 (회의 전 미리 정리)|
|논의 내용|안건별로 오간 이야기의 핵심 (받아쓰기 ❌, 요약 ⭕)|
|**결정사항**|합의된 결론 (가장 중요)|
|**액션 아이템**|누가 / 무엇을 / 언제까지 (가장 중요)|

## 작성 절차

1. **회의 전 (10분)**: 빈 양식 복사, 메타정보·안건 미리 작성
2. **회의 중**: 논의 내용·결정사항·액션 아이템을 실시간 기록
3. **회의 종료 시 (5분)**: 결정사항·액션 아이템을 참석자들과 즉석에서 한 번 확인 ("이렇게 정리했는데 맞나요?")
4. **회의 후 (1일 이내)**: 정리해서 참석자 + 관련자에게 공유

## 자주 하는 실수

- **받아쓰기식 기록** — 한 줄도 빠짐없이 적으려다 핵심이 묻힘. 요약·결정·액션만 잡으면 됨
- **결정사항이 모호** — "검토하기로 함" 같은 표현 ❌, "X를 Y까지 결정"으로 명확히
- **액션 아이템에 담당·마감 없음** — 누구도 안 하게 됨. 반드시 담당자 + 마감일
- **회의 종료 시 즉석 확인 안 함** — 나중에 "그런 결정 한 적 없는데"가 나옴
- **공유 안 함** — 본인만 갖고 있으면 무용지물
- **누적 관리 안 함** — 매번 새 문서로 만들고 흩어져서 못 찾음. DB로 관리

## 작성 후 체크

- [ ] 일시·참석자가 명시되어 있는가
- [ ] 결정사항이 명확한 문장으로 정리되어 있는가
- [ ] 액션 아이템에 담당자·마감일이 모두 있는가
- [ ] 회의 종료 시 참석자들과 결정사항을 즉석 확인했는가
- [ ] 24시간 내에 참석자 + 관련자에게 공유했는가
