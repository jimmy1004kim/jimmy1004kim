## 이 문서는

프로젝트의 **출발점이 되는 한 장짜리 합의 문서**. 왜 이걸 하는지, 뭘 만드는지, 어디까지 할 건지, 누가 관련되는지를 한곳에 모은다.

이게 합의돼야 다음 문서들이 의미를 가진다. 이거 없이 시작하면 중간에 "그게 아닌데"가 나온다.

## 언제 만드나

프로젝트 시작 시. 첫 주 안에 끝낸다.

## 어떤 툴로

|툴|추천도|이유|
|---|---|---|
|**노션**|⭐ 추천|표·체크박스·링크 자유롭고 협업 편함. 후속 문서와 연결도 쉬움|
|구글 독스|보조|코멘트 협업이 강점. 외부 공유 많을 때|
|MS 워드|보조|공식 보고용. 출력·결재 필요할 때|

처음엔 노션으로 만들고, 외부 공유나 결재가 필요하면 그때 워드로 export.

## 작성 예시

> 진행 중인 샵플링 자동화 프로젝트 기준으로 채운 예시. 실제는 본인 상황에 맞게.

**프로젝트명**: 샵플링 엑셀 처리 자동화 시스템 **작성일**: 2026-05-20 **작성자**: 홍길동 **버전**: v1.0 **상태**: Approved

### 1. 기본 정보

|항목|내용|
|---|---|
|프로젝트명|샵플링 엑셀 처리 자동화 시스템|
|기획 유형|유형 4. 내부 시스템 구축|
|기간|2026-05-20 ~ 2026-08-15|
|예산|인프라 월 0~2만원 (클라우드 무료 티어 활용)|
|총괄 담당|홍길동 (기획 + 개발 겸임)|

### 2. 배경

- 사내 직원 3명이 하루 여러 번 샵플링 엑셀 다운로드 → 가공 → 업로드 작업을 수작업으로 처리 중
- 1회 약 10분, 월 누적 약 30시간 규모
- 휴먼 에러 발생 가능성, 담당자 부재 시 업무 정체
- 향후 유사 사내 자동화 수요 증가 예상 → 단발성 스크립트가 아닌 워크플로 플랫폼으로 구축 필요

### 3. 목적·목표

**목적**: 샵플링 엑셀 수작업을 자동화하고, 향후 사내 자동화 작업을 통합 관리할 수 있는 플랫폼의 기반을 구축한다.

**정량 목표**

- 월 수작업 시간 30시간 → 3시간 이하 (약 90% 절감)
- 1회 처리 시간 10분 → 5분 이내 (사람 개입 0~1분)
- 휴먼 에러 발생 0건

**정성 목표**

- 담당자 부재 시에도 작업 연속성 확보
- 모든 실행 이력 추적 가능
- 향후 신규 워크플로 추가 시 코드 변경 최소화

### 4. 범위

**포함 (In Scope)**

- 자동화 관리 웹 사이트 (대시보드, 워크플로 등록·조회·실행)
- 워크플로 실행 엔진 (단계별 분리, 상태 저장, 재시작 가능)
- 샵플링 엑셀 자동화 워크플로 1종 (다운로드 → 가공 → 업로드)
- 스케줄 기능 (Cron)
- 사내 사용자 인증 (단순 로그인)

**제외 (Out of Scope)**

- 샵플링 외 다른 시스템 연동 (향후 별도 워크플로로 추가)
- 외부 공개 서비스
- 사용자 권한 등급 세분화 (단순 로그인까지만)
- Slack/이메일 알림 (후속 단계)
- 모바일 전용 앱

### 6. 성공 기준

|#|지표|측정 방법|목표값|
|---|---|---|---|
|1|월 수작업 시간|자동 실행 횟수 기반 환산|30h → 3h 이하|
|2|1회 사람 개입 시간|모니터링 시간 측정|10분 → 1분 이하|
|3|자동화 성공률|전체 실행 대비 성공 건수|95% 이상|
|4|실패 시 복구 시간|실패 단계부터 재시작 소요|5분 이내|

### 7. 가정·제약

**가정**

- 샵플링은 외부 인터넷에서 접속 가능 (확인 완료)
- 자동화용 계정 정보를 별도로 발급받을 수 있음
- 엑셀 가공 규칙은 명확하게 명세화 가능

**제약**

- 인프라 비용: 클라우드 무료 티어 한도 내 운영
- 인력: 1인 (기획·개발 겸임)
- 기술 스택: Next.js + Node.js + Playwright (사전 정해짐)
- Vercel Free의 Serverless 실행 시간 제한 (10초) → Worker 분리 아키텍처 필수

## 자주 하는 실수

- **너무 길게 씀** — A4 2~3장 넘어가면 안 읽힘
- **목표가 두루뭉술** — "효율 개선" 같은 표현. 숫자로 환산할 수 있어야 함
- **범위가 모호** — 포함만 쓰고 제외를 안 씀. 제외가 더 중요할 때도 많음
- **이해관계자 누락** — 승인자·사용자 빠뜨리면 나중에 발목 잡힘
- **미정인데 결정된 척** — 모르면 "[미정]"이라고 쓰는 게 정직하고 안전함
- **만들고 안 봄** — 합의 후 잊어버리면 무용지물
