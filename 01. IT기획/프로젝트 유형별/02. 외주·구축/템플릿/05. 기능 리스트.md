## 이 문서는

프로젝트가 만들 **모든 기능의 목록**을 한눈에 보여주는 산출물.

요구사항 정의서·기능 정의서와의 관계:

|구분|요구사항 정의서|기능 리스트|기능 정의서|
|---|---|---|---|
|단위|요구사항 1건 (REQ-XXX)|**기능 1개 (F-XXX)**|기능 1개 상세|
|깊이|무엇을 원하는가|**무엇을 만들 것인가 (목록)**|어떻게 작동하는가|
|청중|양 당사자·법무|**전체 (한눈에 파악)**|개발·QA|
|길이|길음 (페이지)|**짧음 (1~2 페이지 표)**|길음 (페이지)|

**핵심**: 기능 리스트는 **"몇 개의 기능이 있는가, 어디까지 만들 것인가"를 한눈에** 보여주는 인덱스. T1의 기능 정의서가 "1개 기능 상세"라면, T2의 기능 리스트는 "전체 기능 목록".

### T1 기능 정의서 vs T2 기능 리스트

T1과 T2 모두 "기능"을 다루지만 강조점이 다르다:

|구분|T1 기능 정의서|T2 기능 리스트|
|---|---|---|
|강조|**각 기능의 상세** (어떻게 작동)|**전체 기능 인벤토리** (몇 개·무엇·범위)|
|용도|개발의 입력|**계약·견적·검수의 기준**|
|형식|페이지 (기능당 1페이지)|표 (전체를 1~2 페이지)|
|시점|설계 단계|요구사항 확정·계약 직후|

**외주 프로젝트에서 기능 리스트가 특히 중요한 이유**:

- 계약 범위가 "이 기능들"로 명시됨 → **포함·제외 명확**
- Change Order의 기준이 됨 → **새 기능 = 추가 견적**
- 검수의 기준이 됨 → **모든 기능이 작동해야 검수 통과**
- 고객·내부 팀이 한눈에 진행률 파악

**T1과의 관계**: T1의 기능 정의서 형식을 그대로 **각 기능 상세**로 사용 가능. T2 기능 리스트는 그 인벤토리·요약.

## 언제 만드나

- 요구사항 정의서 v1.0 확정 직후 (Phase 1 종료)
- 계약·SoW 첨부 시 (계약 범위 명시)
- 견적 산정 기준으로 (Bottom-up 견적)
- 진행률 추적 시 (개발·QA·검수)
- Change Order 평가 시 (기존 리스트 vs 새 요청)

**기준**: 계약 범위·견적·검수의 객관적 기준이 필요한 모든 시점.

## 작성 팁

- **요구사항 정의서 기반** — 머리로 만들지 말 것. 1요구 → 1~N 기능으로 분해
- **카테고리 분류 일관** — 회원·상품·주문·결제·관리자 등. ID Prefix 일관
- **ID 영구 보존** — 한 번 부여한 ID 재사용 X. 삭제 기능은 결번 처리
- **계약·SoW 첨부 필수** — 이 리스트가 곧 계약 범위. 외주 프로젝트의 핵심 산출물
- **우선순위 명확히** — Critical 60% 이내 권장. 모두 Critical은 무의미
- **요구사항·화면 매핑** — RTM 갱신. 검수의 기준
- **관리자 기능 빠뜨리지 말 것** — 사용자 화면만 적으면 관리자 운영 못 함
- **외부 의존 명시** — POS·PG·인증 등 외부 시스템과 연동되는 기능은 비고 명시
- **CR 발생 시 즉시 갱신** — 새 기능 추가·범위 변경 시 v1.1, v1.2로 버전 관리
- **진행률 주간 갱신** — 살아있는 문서. 정체된 카테고리·기능 빠르게 식별
- **카테고리별 합계 표** — 한눈에 진행 현황 파악
- **Out of Scope 별도 명시** — 거절된 요청·v2 이동된 기능 (Change Order 기록)
- **포트폴리오 자산** — 같은 도메인(자사몰·관리자 등)의 다음 수주에서 70~80% 재사용

## 자주 하는 실수

- **요구사항 정의서 없이 작성** — 머리로 만듦 → 누락·중복 다수
- **카테고리 분류 일관성 없음** — 회원에 결제 섞이거나 → 검색·관리 어려움
- **ID 재사용·재배치** — 삭제 기능 자리에 새 기능 → 추적 불가
- **계약 첨부 누락** — 리스트 있는데 계약에 안 적혀 있음 → "이거 우리가 합의 안 했는데" 분쟁
- **우선순위 모두 Critical** — 우선순위 무의미 → 일정 압박 시 결정 못 함
- **요구사항·화면 매핑 없음** — RTM 없음 → 검수 못 함
- **관리자 기능 누락** — 사용자 화면만 → 운영 불가
- **외부 의존 명시 안 함** — POS·PG 등 의존성 모름 → 일정 지연 시 책임 모호
- **CR 시 갱신 안 함** — 새 기능 추가됐는데 리스트 그대로 → 검수 단계 혼란
- **진행률 추적 안 함** — 정체된 카테고리 식별 못 함 → 마지막에 폭발
- **Out of Scope 누락** — 거절된 요청 기록 안 함 → 같은 요청 반복 들어옴
- **포트폴리오 자산화 누락** — 다음 수주에서 처음부터 작성
