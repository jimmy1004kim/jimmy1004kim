## 이 문서는

고객사의 요청·RFP에 대해 **우리가 무엇을·어떻게·얼마에·언제까지** 만들어 납품할 것인지를 정리한 설득 문서.

견적서·SoW와의 관계:

|구분|제안서|견적서|SoW (작업 명세서)|
|---|---|---|---|
|단위|프로젝트 전체|비용 산정|계약 첨부 명세|
|깊이|**무엇·어떻게·왜 우리**|항목별 비용|범위·산출물·검수 기준|
|청중|고객 의사결정자·평가위원|발주·재무|계약 양 당사자|
|변경 빈도|계약 전까지 수정|계약 시 확정|변경 시 CR로 갱신|

**핵심**: 제안서는 **"왜 우리에게 발주해야 하는가"** 에 답하는 문서. 견적서는 **"얼마인가"**, SoW는 **"무엇을 어디까지"**.

### 제안서의 3가지 목적

1. **이해 (Understanding)** — 고객 문제를 우리가 정확히 이해하고 있음을 보임
2. **해결 (Solution)** — 그 문제를 어떻게 풀 것인지 구체적으로
3. **설득 (Persuasion)** — "왜 우리여야 하는가" — Win Theme

이 세 가지가 균형 잡혀야 좋은 제안서.

### 제안서의 두 가지 사용 시점

|시점|목적|형식|
|---|---|---|
|**사전 제안 (Pre-RFP)**|고객 니즈 발굴 + 우리 솔루션 소개|짧음 (10~15페이지)|
|**공식 제안 (RFP 응답)**|입찰·발주 의사결정|상세 (30~80페이지)|

이 가이드는 **공식 제안** 중심. 사전 제안은 핵심만 추려서 사용.

## 언제 만드나

- 고객사의 공식 RFP 수령 후
- 영업·미팅 후 정식 제안 요청 받았을 때
- 입찰 공고 응답 시
- 기존 고객의 추가 사업 의뢰 시

**기준**: "공식적으로 검토해주세요" 또는 "정식 제안서 주세요" 요청 시.

## 2. 고객 이해

### 2.1 StyleHaus 비즈니스 이해

- 30~40대 여성 캐주얼 의류 브랜드, 2018년 설립
- 오프라인 매장 6개 + 도매 채널 (백화점·온라인 셀러) 중심
- 연 매출 200억, 도매 비중 75%
- 최근 3년 자사몰 부재로 인한 도매 의존도·마진율 압박 심화

### 2.2 고객 문제·니즈

**명시적 니즈 (RFP)**

- 자사몰 구축 (PC + Mobile)
- 결제·재고·회원 시스템
- 관리자 시스템
- 2027-02-01 신규 라인 런칭과 동시 오픈

**우리가 파악한 행간**

- 도매 의존도 완화·자체 채널 확보가 사업 전략적 핵심
- 신규 라인 런칭과 맞물려 마케팅 임팩트 극대화 필요 → **출시일 사수가 가장 중요**
- 사내 IT 인력 부재 → 출시 후 운영 인계·교육이 핵심
- 향후 모바일 앱·해외 진출 가능성 → **확장 가능한 아키텍처** 필요

### 2.3 As-Is (현재 상태)

- 자사몰 없음 (도매·오프라인 매장만)
- 재고 관리: 엑셀 + 수기 (오프라인 매장 6개)
- 고객 데이터: 회원제 부재
- 도매 채널 매출 데이터는 외부 플랫폼에 의존

### 2.4 To-Be (목표 상태)

- 자사몰 + 모바일 웹 운영
- 통합 재고 (오프라인 6개 매장 + 자사몰)
- 회원 데이터 자체 확보·CRM 기반 구축
- 신규 라인 즉시 출시 가능한 운영 인프라
- 관리자 시스템으로 무 IT 인력 운영 가능

## 4. 솔루션 개요

### 4.1 솔루션 한 줄

오프라인·도매 중심 브랜드가 자사몰을 신규 구축하여 **D2C 채널을 확보**하고, 출시 후 **운영팀이 자립**하여 운영할 수 있는 **확장 가능한 자사몰 솔루션**.

### 4.2 핵심 컨셉 다이어그램

```
[고객(PC·Mobile)]
       ↓
[StyleHaus 자사몰]
   ├─ 회원·인증 (NICE)
   ├─ 상품·카테고리
   ├─ 주문·결제 (토스·네이버·카카오)
   ├─ 재고 (오프라인 매장 6개 연동)
   ├─ 배송·반품·CS
   └─ 관리자 시스템
       ↓
[StyleHaus 운영팀]
```

### 4.3 핵심 기능군

|#|기능군|설명|가치|
|---|---|---|---|
|1|회원·인증|본인 인증·소셜 로그인·회원 등급|회원 데이터 직접 확보|
|2|상품·카테고리|상품 등록·옵션(사이즈·컬러)·이미지|의류 특화 옵션|
|3|주문·결제|주문서·결제·쿠폰·할인|통합 결제|
|4|재고|자사몰 + 오프라인 매장 6개 통합|재고 정확성|
|5|배송·반품|배송 조회·환불·교환 정책|의류 반품·교환 특화|
|6|CS|1:1 문의·자주 묻는 질문|자체 CS 운영|
|7|관리자 시스템|주문·재고·회원·상품·통계|운영팀 자립 운영|

### 4.4 기술 아키텍처

- **프론트엔드**: Next.js (PC·Mobile Web SSR), TailwindCSS
- **백엔드**: Node.js + Express, PostgreSQL, Redis
- **인프라**: AWS (EC2·RDS·S3·CloudFront)
- **외부 연동**: 토스페이먼츠·네이버페이·카카오페이, NICE 본인 인증, CJ대한통운 배송 API, SendGrid 이메일
- **확장 고려**: 모바일 앱 (v2) 대비 API-First 설계, 해외 진출 (v2) 대비 다국어 구조

- **RFP 평가 기준 매핑** — RFP에 평가 기준 명시되어 있으면 그것에 맞춰 본문 구성. 채점 가능하게
- **차별화는 근거·실적과 함께** — "전문성" 추상어 ❌, 구체적 사례 + 숫자 ⭕
- **포함만큼 제외가 중요** — Out of Scope 명시. 나중에 분쟁 방지
- **일정 가정·전제 명시** — "고객 응답 1~2일" 같은 전제. 일정 지연 시 책임 분리
- **리스크 솔직히** — 리스크 숨기지 말 것. 식별 + 대응 보여주면 신뢰 ↑
- **시각 자료 활용** — 다이어그램·화면 시안·실적 표. 텍스트만으론 안 됨
- **PPT + PDF 둘 다** — 발표용·검토용 분리 제공
- **법무 검토 필수** — 계약 조건·보안·법무 요구 사항
- **유효 기간 명시** — "이 견적은 ___까지 유효" 명시. 그 이후 재견적
- **포트폴리오 자산** — 잘 쓴 제안서는 다음 수주에 80% 재사용 가능. 자산화 필수

## 자주 하는 실수

- **고객 이해 누락** — 솔루션부터 시작 → "당신 문제를 안 듣는 회사" 인상
- **Win Theme 모호** — "전문성·신뢰" 같은 추상어 → 평가위원이 차별점 못 봄
- **차별화 근거 없음** — "오랜 경험" → 몇 년? 몇 건? 수치 없음
- **Out of Scope 누락** — 포함만 적고 제외 안 적음 → 검수 단계 분쟁
- **일정 가정 누락** — "고객 응답 시간"·"자료 제공 시점" 안 적음 → 지연 시 우리 책임
- **견적 디테일 부족** — 카테고리별 분해 없이 총액만 → 협상 어려움
- **리스크 숨김** — 발견된 리스크 안 적음 → 발생 시 신뢰 손상
- **유사 실적 추상적** — 케이스 스터디 없이 "잘했다"만 → 설득력 부족
- **법무 검토 누락** — 계약 조건·보안 요구 검토 없이 제출 → 계약 단계 분쟁
- **유효 기간 누락** — 6개월 후 같은 견적 적용 요구받음
- **PPT만 제출** — 평가위원이 PDF로 검토하는데 PPT만 보냄 → 가독성 ↓
- **발표 준비 부족** — 제안서 잘 썼는데 발표는 다른 사람 → 일관성 ↓
- **자산화 누락** — 다음 수주에서 처음부터 다시 작성 → 시간 낭비

## 작성 후 체크

- [ ] Executive Summary가 3~5페이지에 핵심을 압축했는가
- [ ] 고객 이해 섹션이 솔루션보다 먼저 나오는가
- [ ] Win Theme이 한 문장 + 차별화 포인트 3~5개로 명확한가
- [ ] 차별화에 구체적 실적·수치 근거가 있는가
- [ ] RFP 평가 기준에 맞춰 본문이 매핑되었는가
- [ ] 기능 범위(In/Out of Scope)가 명확한가
- [ ] 일정에 마일스톤·산출물·결제 트리거가 있는가
- [ ] 견적이 카테고리별 분해되어 있는가
- [ ] 결제 조건(계약금·중도금·잔금)이 명시되었는가
- [ ] 유사 프로젝트 실적·케이스 스터디가 첨부되었는가
- [ ] 투입 인력·역할·경력·투입 비율이 명시되었는가
- [ ] 리스크 식별·대응이 솔직하게 적혔는가
- [ ] 전제(Assumptions)와 고객 측 협조 사항이 명시되었는가
- [ ] 유효 기간이 표지에 있는가
- [ ] 법무 검토 완료되었는가
- [ ] PPT(발표용) + PDF(검토용) 둘 다 준비되었는가
- [ ] 발표 자료·예상 Q&A 준비되었는가
