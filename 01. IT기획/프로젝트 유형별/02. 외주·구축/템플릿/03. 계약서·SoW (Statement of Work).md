## 이 문서는

프로젝트의 **법적 효력이 있는 합의 문서**. 양 당사자가 서명하는 시점부터 모든 책임·권리의 기준이 된다.

제안서·견적서·SoW와의 관계:

|구분|제안서|견적서|계약서 + SoW|
|---|---|---|---|
|효력|설득 자료|공식 청구 근거|**법적 효력**|
|청중|평가위원·의사결정자|발주·재무|**법무·양 당사자**|
|변경|자유|합의 시 재발행|**공식 변경 절차 (CR·계약 부속) 필요**|
|보관|일정 기간|회계 5년|**계약 기간 + 법적 보관 의무**|

**핵심**: 계약서는 **다른 산출물보다 우선하는 최상위 문서**. 분쟁 시 계약서가 기준. 모호하면 모두 우리 책임.

### 계약서 vs SoW의 관계

|구분|계약서 (Contract)|SoW (Statement of Work)|
|---|---|---|
|다루는 것|**법적 권리·의무·조건**|**작업 범위·산출물·검수 기준**|
|내용|책임·보증·면책·분쟁·해지|범위·일정·산출물·인력·CR 절차|
|변경 빈도|거의 안 바뀜|CR 발생 시 부속 SoW로 보완|
|길이|보통 5~15페이지|10~30페이지|

**관계**: 계약서 = 모(母)문서, SoW = 첨부 부속 문서. SoW가 계약서의 "특약·작업 명세"를 담당.

**실무 활용**:

- **계약서**: 본문은 표준화 (회사 표준 계약서 양식)
- **SoW**: 프로젝트마다 새로 작성

이 가이드는 **두 문서를 묶어서** 안내. 실무에선 분리하거나 하나로 합쳐서 운영.

### 계약서의 4가지 핵심 효력

1. **합의 (Agreement)** — 무엇을 어디까지 만들 것인지 합의
2. **보호 (Protection)** — 양 당사자의 권리·이익 보호
3. **분쟁 대응 (Dispute)** — 분쟁 발생 시 해결 기준
4. **법적 효력 (Legal)** — 위반 시 법적 청구·소송 근거

## 언제 만드나

- 제안서·견적서 합의 후 (수주 확정)
- 사전 계약 (NDA·MoU)이 필요할 때
- 변경 발생 시 (CR로 부속 SoW 추가)
- 계약 만료·종료 시 (해지·갱신 합의)

**기준**: 작업 착수 전. **계약 없이 작업 시작 금지**가 원칙.

## 어떤 툴로

|툴|추천도|이유|
|---|---|---|
|**Word + PDF**|⭐ 강력 추천|법무 표준, 회사 양식|
|**전자 계약 (DocuSign·모두싸인·Clipa)**|⭐ 추천|서명·보관·법적 효력 자동화|

**워크플로우**:

1. 내부 작성: Word·노션 (검토용)
2. 법무 검토: Word·Google Docs 코멘트
3. 고객 송부·서명: 전자 계약 (DocuSign·모두싸인)
4. 보관: PDF + 종이 원본 (회사 정책)

7. **서명·계약 발효**
8. **보관·관리** — 양 당사자 보관 + 회계·법무 보관

## 제7조 (산출물 소유권·지적재산권)

### 7.1 산출물 정의

- 본 계약에 의해 을이 갑에게 납품하는 모든 코드·문서·디자인·데이터

### 7.2 소유권 이전 시점

- **최종 검수 통과 + 잔금 결제 완료 시점**에 갑에게 이전

### 7.3 이전 범위

- 산출물의 사용·복제·수정·배포 권리는 갑에게 이전
- 단, 다음은 을의 권리로 유지:
    - 을이 본 계약 전부터 보유한 일반 노하우·라이브러리·프레임워크
    - 을이 본 계약 외 다른 프로젝트에서 재사용 가능한 일반 컴포넌트
- 제3자 라이선스 (오픈소스·외부 라이브러리·SaaS)는 각 라이선스 조건에 따름

### 7.4 양 당사자의 마케팅·포트폴리오 활용

- 을은 갑의 사전 서면 동의 하에 본 프로젝트를 포트폴리오·실적으로 활용 가능
- 비공개 정보는 마스킹·익명화

## 제8조 (하자 보수)

### 8.1 하자 보수 기간

- 출시일로부터 **___개월** 무상 하자 보수

### 8.2 하자의 정의

- SoW 산출물 또는 검수 기준에 미치지 못하는 결함
- 일반적 운영·사용에 따른 정상 마모는 하자 아님

### 8.3 하자 보수 범위

- ✅ 포함: 버그 수정, 검수 기준 미달 항목 보완
- ❌ 불포함: 신규 기능 추가, 사용자 증가에 따른 성능 보강, 외부 환경 변화 대응

### 8.4 하자 보수 절차

- 갑이 하자 발견 시 을에게 서면 통보
- 을은 5영업일 내 조치 시작
- Critical 하자는 24시간 내 대응

## 제9조 (비밀유지 / NDA)

### 9.1 비밀정보의 정의

- 본 계약 수행 중 알게 된 상대방의 비공개 정보 일체
- 사업·기술·고객·재무 정보 포함

### 9.2 비밀유지 의무

- 양 당사자는 비밀정보를 제3자에게 공개·제공·누설하지 않음
- 본 계약 목적 외 사용 금지

### 9.3 비밀유지 기간

- 계약 기간 + 종료 후 **___년** (통상 2~3년)

### 9.4 예외

- 법령에 따른 공개 의무
- 양 당사자의 서면 동의
- 이미 공개된 정보·제3자로부터 적법 취득한 정보

## 제10조 (책임·면책 / Limitation of Liability)

### 10.1 책임 제한

- 양 당사자의 손해배상 책임은 **본 계약 금액을 한도**로 한다
- 단, 고의·중과실의 경우 제한 없음

### 10.2 면책 사유

- 불가항력 (천재지변·전쟁·정부 조치·인터넷 장애 등)
- 상대방의 자료 미제공·승인 지연
- 제3자의 행위 (외부 API 장애·해킹 등)

### 10.3 간접 손해 면책

- 양 당사자는 간접·결과적·특별 손해 (영업 손실·기회비용 등)에 대한 책임 없음

## 제11조 (계약 해지·종료)

### 11.1 일반 해지

- 양 당사자 서면 합의로 해지 가능
- 해지 시 그 시점까지의 작업분에 대해 정산

### 11.2 일방적 해지 사유

다음 경우 상대방은 14일 사전 통지 후 해지 가능:

- 중대한 계약 위반
- 결제 30일 이상 지연 (갑)
- 합의된 일정 ___일 이상 지연 (을)
- 파산·회생 절차 개시

### 11.3 해지 시 산출물·정산

- 해지 시점까지 완성된 산출물은 갑에게 인도
- 그에 상응하는 금액 지급
- 양 당사자 모두 자료 반환·폐기 의무

## 제12조 (분쟁 해결·관할)

### 12.1 협의·중재

- 분쟁 발생 시 30일간 협의로 해결 노력
- 협의 불가 시 양 당사자 합의된 중재기관에 중재 신청 가능

### 12.2 관할 법원

- 협의·중재로도 해결 안 될 경우 **서울중앙지방법원**을 관할로 함

### 12.3 준거법

- 본 계약은 **대한민국 법률**을 준거법으로 한다

## 제13조 (일반 조항)

### 13.1 양도 금지

- 본 계약상 권리·의무는 상대방 사전 서면 동의 없이 제3자에게 양도 불가

### 13.2 통지

- 모든 통지는 서면(이메일 포함)으로 함
- 통지 주소·이메일은 별도 명시

### 13.3 우선순위

- 본 계약서 본문 > 별첨 SoW > 제안서·견적서 순으로 우선 적용
- 충돌 시 본 계약서가 우선

### 13.4 분리 가능성

- 본 계약의 일부 조항이 무효이더라도 나머지 조항은 유효

### 13.5 완전 합의

- 본 계약 이전의 구두·서면 합의는 본 계약으로 대체

## 작성 팁

- **회사 표준 계약서 활용** — 매번 처음부터 X. 표준 양식 + 프로젝트별 SoW
- **법무 사전 검토 필수** — 특히 책임 제한·지적재산권·해지 조항. 한 줄로 큰 손해
- **계약서·SoW 분리 운영** — 계약서는 거의 안 바뀜, SoW는 CR로 자주 갱신
- **우선순위 명시** — 계약서 > SoW > 견적서 > 제안서. 충돌 시 어느 것이 우선인지 사전 합의
- **지적재산권 명확히** — 소유권 이전 시점·범위·예외 (을의 일반 노하우 보호). 모호하면 분쟁
- **포트폴리오 활용 조항** — 을이 포트폴리오 활용 가능하도록 명시. 영업 자산
- **하자 보수 범위 명확** — 포함·불포함 명시. "신규 기능 추가 = 별도 견적"
- **책임 한도** — 통상 계약 금액 한도. 고객이 무제한 책임 요구 시 거절
- **간접 손해 면책** — 영업 손실·기회비용 면책 명시. 안 하면 천문학적 청구 가능
- **불가항력 명시** — 천재지변·정부 조치·외부 API 장애 면책
- **검수 무응답 자동 통과** — 갑이 검수 안 하고 끄는 경우 방지. 통지 의무 동반
- **핵심 인력 보호** — 핵심 인력 교체 시 동의 + 동등 역량 후임자. 인력 빼가기 방지
- **종료 후 자료 반환·폐기** — 비밀 정보 사후 처리 명시
- **분쟁 해결 협의 우선** — 바로 소송 X, 30일 협의 후 중재 → 법원 순
- **전자 계약 도입** — DocuSign·모두싸인 등. 서명 속도·보관 용이
- **변경 시 부속 SoW로** — 본 계약 안 건드리고 SoW v1.1, v2.0으로 갱신
- **자산화 필수** — 표준 계약서·SoW는 다음 수주 80% 재사용. 자산 가치 ↑

## 자주 하는 실수

- **표준 계약서 없이 매번 새로** — 시간 낭비 + 누락 위험
- **법무 검토 생략** — 특히 책임·지적재산권 조항. 한 줄에 회사 망함
- **지적재산권 모호** — 소유권 이전 시점·범위 모호 → 분쟁
- **포트폴리오 활용 조항 누락** — 출시 후 갑이 거절 → 영업 자산 손실
- **하자 보수 범위 모호** — "신규 기능 추가까지 하자"로 해석되면 무료 추가 개발
- **책임 한도 없음** — 무제한 책임 → 작은 사고에도 회사 망할 가능성
- **간접 손해 면책 누락** — 영업 손실 청구 가능 → 천문학적 청구
- **불가항력 누락** — 외부 API 장애·천재지변에도 우리 책임
- **검수 무응답 처리 없음** — 갑이 검수 안 하고 끔 → 잔금 지급 거부 → 우리만 손해
- **핵심 인력 보호 없음** — 좋은 인력 갑이 빼가서 자체 운영 → 우리 후속 사업 손실
- **CR 절차 없음** — 추가 요청 매번 협상 → 거절 못 함, 누적되면 적자
- **종료 후 자료 반환·폐기 누락** — 비밀 정보 사후 관리 불명확
- **분쟁 해결 협의 단계 없음** — 바로 소송 → 양 당사자 모두 손해
- **우선순위 모호** — 계약서·SoW·견적서·제안서 충돌 시 기준 없음 → 분쟁

### 계약서 본문

- [ ] 당사자 정보·사업자등록번호·담당자 명시되었는가
- [ ] 계약 목적·기간·금액·결제 조건이 명확한가

- [ ] 비밀유지 (기간·예외) 조항이 있는가
- [ ] 하자 보수 (기간·범위·절차) 조항이 있는가
- [ ] 책임 제한 (한도·간접 손해 면책·불가항력) 조항이 있는가
- [ ] 해지 조항 (사유·절차·정산) 명확한가
- [ ] 분쟁 해결 (협의·중재·관할 법원·준거법) 명시되었는가

- [ ] 양도 금지·통지·완전 합의 조항 있는가
- [ ] 양 당사자 서명·날인 칸 있는가

### SoW

- [ ] In Scope·Out of Scope 명확한가
- [ ] 경계가 모호한 항목이 명시되었는가
- [ ] 산출물 리스트 + 형식 + 납품 시점 + 검수 기준 링크 있는가
- [ ] 일정·마일스톤 + 검수·결제 트리거 명시되었는가
- [ ] 일정 가정 (Assumptions) 명시되었는가
- [ ] 투입 인력 + 핵심 인력 보호 조항 있는가
- [ ] 검수 절차 + 검수 무응답 자동 통과 조항 있는가
- [ ] CR 절차 + 무상 흡수 vs 추가 견적 기준 있는가
- [ ] 고객 측 협조 사항 명시되었는가

### 운영

- [ ] 법무 검토 완료되었는가
- [ ] 회사 표준 양식 기반인가
- [ ] 전자 계약 도구 (DocuSign 등) 사용했는가
- [ ] 양 당사자 서명·날인·보관 완료되었는가
- [ ] 별첨 (SoW·견적서·NDA·인력 프로필 등) 모두 첨부되었는가
