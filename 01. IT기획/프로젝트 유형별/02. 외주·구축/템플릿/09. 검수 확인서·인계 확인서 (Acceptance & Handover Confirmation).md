## 이 문서는

외주 프로젝트의 **검수 통과·인계 완료를 양 당사자가 공식 서명하는 문서**.

검수 기준서·납품 산출물 리스트와의 관계:

| 구분  | 검수 기준서   | 검수 확인서 / 인계 확인서       | 납품 산출물 리스트 |
| --- | -------- | --------------------- | ---------- |
| 단위  | 검수 기준·절차 | **검수·인계 결과 서명**       | 산출물 목록     |
| 깊이  | 기준·통과 조건 | **이 시점에 통과·인계 완료 확인** | 산출물 인벤토리   |
| 효력  | 검수 진행 근거 | **결제 트리거·소유권 이전 트리거** | 인계 대상 명시   |
| 시점  | 계약 첨부    | **마일스톤 통과·인계 시점**     | 인계 시점      |

**핵심**: 이 문서가 서명되면 **결제·소유권·책임 이전이 공식 발효**. 외주 프로젝트의 가장 결정적 순간의 문서.

### 검수 확인서 vs 인계 확인서

|구분|검수 확인서|인계 확인서|
|---|---|---|
|시점|**각 마일스톤 검수 통과 시** (M1·M2·M3·M4·M5)|**프로젝트 최종 인계 시** (M5 + 안정화 후)|
|효력|결제 트리거 (특히 M2 중도금·M5 잔금)|**소유권 이전·하자 보수 기간 시작**|
|범위|해당 마일스톤 산출물|**전체 산출물·계정·운영 인계**|
|빈도|5회 (M1~M5)|1회 (프로젝트 종료)|

두 문서는 별도 산출물이지만 양식 유사. 본 가이드는 두 문서 모두 포함.

### 왜 이 문서가 중요한가

1. **결제의 법적 근거** — "M2 검수 통과 = 중도금 청구 권리". 서명 없으면 결제 청구 불가
2. **소유권 이전 시점 명확화** — 코드·문서·계정의 ownership 이전 (계약 제7조)
3. **하자 보수 기간 시작점** — 인계 확인서 서명 = 하자 보수 카운트다운 시작
4. **분쟁 시 결정적 증거** — "이 시점에 양 당사자 합의했다"의 명확한 기록
5. **회계·세무 근거** — 매출 인식 시점

## 언제 만드나

### 검수 확인서

- M1·M2·M3·M4·M5 각 마일스톤 검수 통과 직후
- 특히 **M2 (중도금)·M5 (잔금)** 은 결제 트리거 — 반드시 서명

### 인계 확인서

- 출시 후 안정화 기간 종료 시점 (보통 출시 + 2주 후)
- 모든 산출물·계정 인계 완료 + 운영팀 교육 완료 + 안정화 가동률 충족 시
- 잔금 청구 직전

**기준**: 결제·소유권·하자 보수 등 **법적·재무적 효력이 이전되는 시점**.

## 어떤 툴로

|툴|추천도|이유|
|---|---|---|
|**Word + PDF**|⭐ 강력 추천|법적 문서 표준|
|**전자 계약 (DocuSign·모두싸인·Clipa)**|⭐ 강력 추천|서명 속도·법적 효력·보관 자동|
|노션 (관리용)|보조|검수 결과 기록·인계 진행률|
|Excel|보조|인계 항목 체크리스트|

**최적**: 노션 (관리·체크리스트) + Word·PDF (공식 양식) + 전자 계약 (서명·보관).

4. 운영팀 교육 이행 확인
5. 안정화 기간 결과 확인
6. 하자 보수 기간 명시 (시작·종료일)
7. 잔존 이슈·후속 작업 (있다면)

6. **확인서 작성·서명**
7. **잔금 청구·하자 보수 시작**
