## 이 문서는

외주 프로젝트에서 **고객과의 모든 회의·협의 기록을 정리한 공식 문서**.

공통 회의록 (C-04)과의 차이:

|구분|공통 회의록 (C)|T2 고객 미팅 회의록|
|---|---|---|
|청중|내부 팀|**양 당사자 (고객 + 우리)**|
|효력|내부 합의 기록|**계약·검수의 근거**|
|합의 사항|결정·다음 액션|**공식 합의·서명 가능 수준**|
|변경 영향|작업 영향|**계약 영향 (CR로 발전 가능)**|
|보관 의무|일정 기간|**계약 기간 + 법적 보관**|

**핵심**: 고객 미팅 회의록은 **"오늘 우리 무엇을 합의했는가"** 의 공식 기록. 추후 분쟁 시 결정적 증거. **이메일·구두 합의보다 회의록이 우선**.

### 외주 프로젝트에서 회의록의 4가지 책임

1. **합의 기록** — 양 당사자 합의 사항 명문화
2. **결정 추적** — 누가·언제·왜 결정했는지
3. **변경 근거** — CR로 발전될 수 있는 변경 요청 출처
4. **검수 근거** — "이 부분은 회의에서 합의된 대로" 라는 기준

### 고객 미팅의 주요 유형

|유형|주기·시점|회의록 형식|
|---|---|---|
|**킥오프 회의**|계약 직후 1회|상세 (목표·역할·일정 합의)|
|**주간 정기 회의**|매주 1회|표준 (진행률·이슈·다음 액션)|
|**마일스톤 검수 회의**|M1·M2·M3·M4·M5 시점|상세 + 검수 결과|
|**이슈·긴급 회의**|필요 시|결정·합의 중심|
|**변경 요청 회의 (CR)**|CR 발생 시|변경 내용·영향·합의|
|**종료·인계 회의**|프로젝트 종료 시점|인계 사항·잔여 이슈|

이 가이드는 **모든 유형 공통 양식** + **유형별 추가 항목**.

## 언제 만드나

- 고객과 진행한 모든 회의·통화 (15분 이상)
- 1:1 미팅 (담당자 간 협의)도 핵심 결정·합의 있으면 작성
- 이메일·메신저로 진행된 중요 합의도 회의록 형태로 정리
- 회의 직후 24시간 이내 (기억 휘발 전)

**기준**: "이 합의로 작업 방향이 결정되거나 일정·범위·비용이 바뀔 수 있는 모든 협의".

## 작성 절차

1. **회의 전**: 의제 사전 공유 (24시간 전 권장)
2. **회의 중**: 핵심 논의·결정·액션 메모 (한 사람 전담)
3. **회의 직후**: 24시간 이내 초안 작성
4. **이해관계자 회람**: 양 당사자 검토 (48시간 이내)
5. **확정·발효**: 양 당사자 합의 완료 → 공식 회의록 v1.0
6. **공유·보관**: 노션·이메일·PDF
7. **액션 추적**: 액션 아이템은 별도 추적 (이슈관리·다음 회의 의제)

## 작성 팁

- **24시간 이내 작성** — 기억이 휘발되기 전. 회의 중 메모 → 회의 직후 정리
- **회의 중 1명 전담 메모** — PM 또는 기획. 다른 사람은 회의 집중
- **요점만, 받아쓰기 X** — 발언자·요지·결정 위주. 단어 그대로 X
- **결정 사항을 별도 섹션으로** — 논의와 결정 분리. 결정은 ID 부여 (D-XXX)
- **결정자·일자 명시** — "양 당사자 합의" + 누구·언제. 분쟁 시 결정적 증거
- **액션 아이템은 SMART** — Specific·Measurable·Assignee·Realistic·Time-bound. 모호하면 미실행
- **회람·확인 절차** — 회의 직후 24h 내 양 당사자 회람. 48h 내 확정·발효
- **이메일 답신을 서명 갈음** — 양 당사자 이메일 답신 ("내용 확인했습니다")으로 발효 가능. 분쟁 시 효력 있음
- **변경 요청 (CR) 별도 추적** — 회의에서 발생한 CR 후보는 별도 ID 부여 (CR-XXX) + 후속 절차 명시
- **마일스톤 검수 회의는 서명 필수** — 검수 통과·결제 트리거. 양 당사자 서명·날인
- **노션 DB로 관리** — 회의록 1건 = 1행. 회의 유형·일자·결정 사항·CR로 검색·필터
- **민감 정보 마스킹** — 비공개 매출·고객 데이터는 회의록에 직접 적지 말 것. 별도 자료로 참조
- **포트폴리오 자산** — 잘 쓴 회의록은 다음 수주의 케이스 스터디. 합의·결정·변경 흐름 정리

- **24시간 늦게 작성** — 기억 휘발 → 결정 사항 누락·왜곡
- **받아쓰기처럼** — 모든 발언 받아씀 → 핵심 안 보임
- **결정·논의 섞임** — "이것도 의논했다" → 무엇이 결정인지 모호
- **결정자·일자 누락** — 분쟁 시 "이거 누가 결정했어?" → 책임 모호

- **포트폴리오 자산화 누락** — 합의·결정 흐름을 다음 수주에서 처음부터
