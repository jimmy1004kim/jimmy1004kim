## 이 문서는

운영 중인 서비스의 **화면 단위 변경 (UI·인터랙션·요소 추가·삭제·재배치)을 Before·After로 상세히 정의한 문서.**

T3 산출물 흐름에서의 위치:

```
[T3-4 개선 기획] → [T3-6 기능 변경 정의서] + [T3-7 화면 변경 정의서] + [T3-9 회귀 테스트]
                       (기능·로직 단위)         (화면·UI 단위)         (검증)
```

T1·T2와의 차이:

|구분|T1·T2 화면 정의서|**T3 화면 변경 정의서**|
|---|---|---|
|시점|신규 서비스 출시 전·외주 구축|**운영 중 서비스 개선 시**|
|단위|화면 1개 (P-XXX) 전체 명세|**변경 1건** (SC-XXX)|
|깊이|전체 화면 명세 (요소·인터랙션·상태)|**변경 부분만**, Before·After 비교|
|강조|What·How|**무엇이 어떻게 달라지는가**|

**핵심**: T3 화면 변경 정의서는 **"변경된 부분"**의 상세. Before 스크린샷·After 시안 양쪽 명시, 시각적 비교가 중심.

### T3-6 기능 변경 정의서 vs T3-7 화면 변경 정의서

|구분|T3-6 기능 변경 정의서|T3-7 화면 변경 정의서|
|---|---|---|
|단위|**기능 단위** (F-XXX)|**화면 단위** (P-XXX)|
|강조|**로직·동작**|**UI·인터랙션**|
|청중|PM·개발·QA|**디자인·프론트엔드·QA**|
|시각화|로직 흐름|**Before·After 스크린샷·시안**|
|산출물|코드·API|**Figma 시안·CSS·컴포넌트**|

같은 개선이라도 기능과 화면은 별도 문서. 한 화면에 여러 기능 변경 영향이 있을 수 있고, 반대도 마찬가지.

### 화면 변경의 4가지 유형

|유형|의미|처리 강조|
|---|---|---|
|**요소 추가 (Add)**|새 UI 요소 추가 (버튼·섹션·필드)|신규 요소 명세·기존 레이아웃 영향|
|**요소 변경 (Modify)**|기존 요소 동작·디자인·문구 변경|Before·After 비교, 시각 강조|
|**요소 삭제 (Remove)**|기존 요소 제거|사용자 영향·대체 수단|
|**재배치 (Rearrange)**|위치·순서 변경|사용자 학습 영향·이전 위치 안내|

### 화면 변경의 7가지 측면

|측면|예시|
|---|---|
|**레이아웃**|영역 추가·제거·재배치|
|**인터랙션**|클릭·호버·드래그·키보드·터치|
|**시각 디자인**|색상·타이포·간격·아이콘|
|**콘텐츠**|텍스트·이미지·라벨·문구|
|**상태**|정상·로딩·빈·에러·성공|
|**반응형**|모바일·태블릿·데스크탑|
|**접근성**|키보드 네비·스크린리더·색대비|

본 문서는 **7가지 모두** 명시.

// MatchingResults.jsx
import { useExperiment } from '@/hooks/useExperiment';

function MatchingResults({ matchings }) {
  const isVariant = useExperiment('matching_weight_v2');

  return (
    <div>
      {matchings.map(m =>

  );
}

## 자주 하는 실수

- **Before 스크린샷 누락** — After만 적음 → 변경 사항 모호
- **변경 유형 안 분류** — Modify·Add·Remove·Rearrange 혼용
- **상태별 시안 누락** — 정상만, 로딩·빈·에러 없음
- **반응형 누락** — 데스크탑만, 모바일 ❌
- **접근성 미검토** — 색대비·키보드 네비 빠뜨림
- **A/B 시각 분기 모호** — Control·Variant 어디서 어떻게 분기되는지 모름
- **인터랙션 정적 시안만** — 동적 변화 안 보임 (Loom 없음)
- **디자인 시스템 영향 누락** — 신규 컴포넌트 식별 X
- **회귀 영향 분석 X** — 기존 사용자 학습 영향 놓침
- **개발 핸드오프 부족** — Figma 링크만, 명세 없음
- **승인자 누락** — 디자인·개발·QA·PM 단독 결정
- **포트폴리오 자산화 누락** — Before·After 시각적 자산 손실

## 작성 후 체크

- [ ] 변경 ID·관련 산출물 (IMP·FC·HYP·EXP) 연결되었는가
- [ ] 변경 유형 (Modify·Add·Remove·Rearrange) 명시되었는가
- [ ] Before 스크린샷 + After 시안 양쪽 있는가
- [ ] Before vs After 비교 표 한눈에 파악되는가
- [ ] 7가지 측면 (레이아웃·인터랙션·시각·콘텐츠·상태·반응형·접근성) 모두 다뤘는가
- [ ] 상태별 시안 (정상·로딩·빈·에러·성공) 있는가
- [ ] 반응형 시안 (모바일·태블릿·데스크탑) 있는가
- [ ] 접근성 검토 (색대비·키보드·스크린리더·aria-label) 완료되었는가
- [ ] 인터랙션·애니메이션 명세되었는가
- [ ] Loom 데모 (해당 시) 있는가
- [ ] 디자인 시스템 영향 (신규 컴포넌트·토큰) 명시되었는가
- [ ] A/B 시각 분기 (해당 시) Control·Variant 양쪽 시안 있는가
- [ ] 회귀 영향 (사용자 학습·다른 화면) 분석되었는가
- [ ] 일정·인력 명확한가
- [ ] 관련 산출물 (Figma·디자인 시스템·구현 코드) 연결되었는가
- [ ] 디자인·프론트엔드·QA·PM 승인되었는가
- [ ] 포트폴리오 자산화 절차 있는가
