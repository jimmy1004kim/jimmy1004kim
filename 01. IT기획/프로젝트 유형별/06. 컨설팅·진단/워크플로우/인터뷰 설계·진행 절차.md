## 이 문서는

진단 프로젝트의 **가장 중요한 정보 수집 활동인 인터뷰를 "어떻게 설계하고·진행하고·기록하고·분석하는가"의 표준 절차**.

T6 산출물 구조에서의 위치:

```
[T6-11 컨설팅·진단 표준 절차] (전체 흐름)
        ↓
[T6-12 인터뷰 절차] ← 본 문서 (Phase 2 핵심 활동 상세)
        ↓ 활용
[T6-3 인터뷰 가이드 (산출물)]
[T6-4 AS-IS 분석 (인터뷰 → 분석)]
```

### 왜 인터뷰가 진단의 핵심인가

진단 정보 수집의 4가지 방법 중 **인터뷰가 가장 풍부·깊이**:

|방법|강점|약점|
|---|---|---|
|**인터뷰** ⭐|깊이·맥락·숨은 니즈·감정|시간·주관·편향|
|설문|정량·다수·통계|깊이 ↓·맥락 ↓|
|관찰|실제 행동·현장|시간·해석|
|데이터 분석|객관·정량|맥락·이유 ↓|

→ **인터뷰 = "왜·어떻게·진짜 무엇" 을 알아내는 핵심**

### 인터뷰 절차의 4대 역할

|역할|의미|
|---|---|
|**깊이 있는 정보**|표면 X·근본 원인·맥락|
|**이해관계자 정렬**|인터뷰 자체가 참여·신뢰|
|**가설 검증**|가설 확인·기각·수정|
|**민감 정보 수집**|번아웃·이직·불만 (설문 X)|

### 인터뷰의 5단계 프로세스

```
[1. 설계] 대상·질문·일정
   ↓
[2. 준비] 사전 정보·라포·환경
   ↓
[3. 진행] 오프닝·본질문·심화·클로징
   ↓
[4. 기록] 노트·녹음·즉시 정리
   ↓
[5. 분석] 코딩·패턴·인사이트
```

### 인터뷰 유형 (3가지)

|유형|특징|적용|
|---|---|---|
|**구조화 (Structured)**|정해진 질문·순서|비교·정량 필요 시|
|**반구조화 (Semi-structured)** ⭐|핵심 질문 + 유연 심화|**진단 표준·권장**|
|**비구조화 (Unstructured)**|자유 대화|탐색·초기|

→ 진단은 **반구조화** 가 표준 (일관성 + 깊이)

### 좋은 질문의 5대 원칙

|원칙|나쁜 예|좋은 예|
|---|---|---|
|**개방형**|"만족하세요?" (예/아니오)|"어떤 점이 어려우신가요?"|
|**중립적**|"이 시스템 불편하죠?" (유도)|"이 시스템 사용 경험은 어떠세요?"|
|**구체적**|"데이터 어때요?" (막연)|"지난주 분석 요청한 경험을 말씀해주세요"|
|**비판단적**|"왜 안 하셨어요?" (비난)|"어떤 점이 방해가 되었나요?"|
|**하나씩**|"도구랑 교육이랑 어때요?" (복합)|(분리) "도구는 어떠세요?"|

### 질문 기법 (3가지)

|기법|의미|예시|
|---|---|---|
|**5 Whys**|근본 원인 파고들기|"왜 그럴까요?" 반복|
|**STAR**|구체적 경험 끌어내기|Situation·Task·Action·Result|
|**Funnel**|넓게 → 좁게|일반 → 구체|

### 인터뷰 대상 선정 (대표성)

|층위|대상|인원 (25명 예시)|
|---|---|---|
|**의사결정자**|CEO·CPO·CTO·CDO|4|
|**핵심 협업**|데이터팀 (DA·DE)|4|
|**부서 리드**|제품·마케팅·영업·CS·재무 리드|6~8|
|**실무자**|각 부서 데이터 사용 실무자|8~10|
|(소수 의견)|신규 입사자·불만 표출자|1~2|

→ **대표성 + 다양성** 핵심

### 인터뷰의 민감성 (T6-10과 연결) ⭐

인터뷰에서 **민감 정보 (번아웃·이직·불만·갈등)** 가 나옴:

- 비밀 보장 (익명화)
- 비판단적 경청
- 인터뷰 내용 ≠ 개인 식별 보고
- 신뢰 = 진실의 전제

### 인터뷰 진행의 황금 비율 (60분 기준)

|단계|시간|활동|
|---|---|---|
|**오프닝·라포**|5분|인사·목적·비밀 보장|
|**워밍업**|5분|역할·일상 (쉬운 질문)|
|**본 질문**|35분|핵심 질문·심화|
|**심화·탐색**|10분|5 Whys·구체 사례|
|**클로징**|5분|추가 의견·감사·후속|

### 3.1 대상 선정 (데이터원더 25명)

|층위|대상|인원|인터뷰어|
|---|---|---|---|
|의사결정자|김CEO·박CPO·박CTO·김CDO|4|Lead|
|핵심 협업|DA 2·DE 2|4|Lead·Senior 1|
|부서 리드|제품·마케팅·영업·CS·재무·디자인·QA|7|Senior 1·2|
|실무자|각 부서 데이터 사용자|8|Senior 2·Junior|
|소수 의견|신규 입사자·불만 표출자|2|Senior 1|
|**합계**||**25**||

**선정 기준**:

- 대표성 (전 부서·전 직급)
- 다양성 (긍정·부정·중립)
- 핵심성 (의사결정·핵심 협업 필수)

### 3.2 질문 설계 (반구조화)

#### 공통 질문 (전 대상)

1. 본인 역할·데이터 사용 빈도는?
2. 데이터로 의사결정한 최근 경험은? (STAR)
3. 데이터 사용 시 가장 어려운 점은?
4. 분석이 필요할 때 어떻게 하시나요?
5. 우리 회사 데이터를 신뢰하시나요? 이유는?

#### 역할별 심화 질문

|대상|심화 질문|
|---|---|
|**CEO·CPO**|데이터 전략·직관 vs 데이터·시리즈 C|
|**CDO**|데이터팀 역할·번아웃·우선순위·비전|
|**DA·DE**|업무 부담·역할 만족·이직 의향·개선 희망|
|**부서 리드**|분석 요청 경험·대기·신뢰·셀프 분석|
|**실무자**|데이터 접근·리터러시·교육 필요|

- 사전 자료 (대시보드·분석 요청 이력)

## 5. Step 3: 진행 (60분 기준)

### 5.1 오프닝 (5분)

**스크립트 예시**:

> "안녕하세요. 시간 내주셔서 감사합니다. 저는 AIOps Korea의 홍길동입니다. 오늘은 데이터원더의 데이터 활용 현황을 이해하기 위해 — 약 1시간 정도 말씀 나누고 싶습니다.
> 
> 먼저 말씀드릴 것은 — **이 인터뷰는 누구를 평가하는 게 아닙니다**. 솔직한 경험과 의견을 듣는 게 목적이고, **개인이 식별되지 않도록 익명으로 정리**됩니다. 편하게 말씀해주시면 됩니다.
> 
> 기록을 위해 녹음을 해도 괜찮을까요? (동의 확인)"

**핵심**:

- 목적·비밀 보장 명확
- 평가 X·경청 O
- 녹음 동의

### 5.2 워밍업 (5분)

- 쉬운 질문 (역할·일상)
- 긴장 완화·라포

> "먼저 — 데이터원더에서 어떤 일을 하고 계신지, 데이터를 평소 얼마나 자주 사용하시는지 편하게 말씀해주세요."

### 5.3 본 질문 (35분)

- 공통 질문 → 역할별 심화
- 개방형·중립적
- **경청 70%·질문 30%**
- 침묵 견디기 (생각할 시간)

> "데이터로 의사결정을 하신 최근 경험을 하나 떠올려 — 어떤 상황이었고, 어떻게 하셨는지 말씀해주세요." (STAR)

### 5.4 심화·탐색 (10분)

- 5 Whys (근본 원인)
- 구체 사례 요청
- 감정·맥락 탐색

> "방금 '분석 요청이 오래 걸린다'고 하셨는데 — 가장 최근에 그런 경험을 구체적으로 말씀해주실 수 있을까요? 그때 어떤 기분이셨어요?"

### 5.5 클로징 (5분)

- 추가 의견
- 마법 지팡이 질문
- 감사·후속

> "혹시 제가 묻지 않았지만 꼭 말씀하고 싶은 게 있으세요?" "만약 마법 지팡이로 딱 하나를 바꿀 수 있다면 — 무엇을 바꾸시겠어요?" "감사합니다. 추가로 생각나시는 게 있으면 언제든 연락 주세요."

## 6. Step 4: 기록 (인터뷰 직후)

### 6.1 기록 원칙

|원칙|내용|
|---|---|
|**즉시 정리**|인터뷰 후 30분 내 (기억 생생)|
|**녹음 + 노트**|녹음 백업·노트 핵심|
|**사실 vs 해석 구분**|발언 (사실) + 인터뷰어 메모 (해석)|
|**인용 표시**|핵심 발언 그대로 (익명)|

### 6.2 인터뷰 노트 템플릿

```
[인터뷰 #N]
- 일시·대상 (익명 코드: DM-CEO·DM-DA1 등)
- 역할·부서

[핵심 발언]
- "분석 요청하면 보통 2주는 기다려요" (DM-마케팅-리드)
- "MAU가 회의마다 다른 숫자가 나와요" (DM-CPO)

[관찰·해석 (인터뷰어 메모)]
- 분석 대기에 대한 불만 강함
- 데이터 신뢰 낮음

[가설 검증]
- H1 (DA 부족): △ (구조 문제 시사)
- H2 (정의 불일치): ○ 확인

[인용 가능 발언 (보고서용·익명)]
- "..."
```

### 6.3 익명화

## 8. 질문 기법

### 8.1 5 Whys (근본 원인)

```
"분석 요청이 오래 걸린다"
  → 왜? "DA가 바빠서"
  → 왜? "요청이 너무 많아서"
  → 왜? "직접 못 봐서"
  → 왜? "정의를 몰라서·도구가 없어서"
  → 왜? "정의 문서가 없어서"
  ⇒ 근본: Governance 부재
```

### 8.2 STAR (구체 경험)

|단계|질문|
|---|---|
|**S**ituation|"어떤 상황이었나요?"|
|**T**ask|"무엇을 하려고 하셨나요?"|
|**A**ction|"실제로 어떻게 하셨나요?"|
|**R**esult|"결과는 어땠나요?"|

→ 추상 X·구체 경험 O

### 8.3 Funnel (넓게 → 좁게)

```
일반: "데이터 사용 경험은 어떠세요?"
  ↓
구체: "분석 요청은 어떻게 하세요?"
  ↓
심화: "지난주 그 요청은 어떻게 됐나요?"
```

### 8.4 침묵·경청 기법

- 답변 후 2~3초 침묵 → 추가 발언 유도
- "조금 더 말씀해주시겠어요?"
- 반영적 경청: "그러니까 ~하다는 말씀이시죠?"
