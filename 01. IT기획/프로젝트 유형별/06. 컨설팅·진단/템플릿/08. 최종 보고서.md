## 2. 진단 배경·목적 (3p)

### 2.1 진단 배경

데이터원더는 시리즈 B 150억 투자 (2025) 후 빠른 성장 단계에 있습니다. MAU 30만·B2B 협업 도구 시장 한국 3위 위치에서 **시리즈 C 진입을 위한 데이터 기반 성장 입증** 이 필요합니다.

그러나 다음과 같은 내부 고민이 누적되고 있습니다:

- "데이터는 많은데 의사결정은 직관 의존"
- "분석 요청 누적 — DA 2명·대기 2주+"
- "대시보드 30+개 산재·신뢰성 ↓"
- "데이터팀 (4명) 번아웃·이직 우려"

이에 김CEO·박CPO·김CDO는 **외부 객관적 진단** 을 통해 현재 상태를 파악하고 향후 12개월 데이터 전략을 수립하기로 결정했습니다.

### 2.2 진단 목적 (3가지)

    - 동종 업계·Best Practice 대비 위치
2. **핵심 문제·근본 원인 식별**
    
    - 표면 증상 (대기·신뢰 ↓) 의 근본 원인
    - 우선순위와 영향도
3. **12개월 데이터 전략·로드맵 수립**
    
    - 4대 개선 방향

## 3. 진단 방법론·프레임워크 (5p)

### 3.1 적용 프레임워크 — Data Maturity Framework (DMF)

AIOps Korea 자체 프레임워크 — Gartner·McKinsey·DCAM 참고하여 5축으로 구성:

```
                  [Strategy]
                  데이터 비전·전략·KPI
                       │
       [People]      [Process]      [Technology]
       조직·스킬·    분석 요청·     도구·인프라·
       리터러시      셀프 서비스    자동화
                       │
                  [Governance]
                  정의·품질·보안·접근
```

### 3.2 성숙도 5단계

|Level|명칭|특징|
|---|---|---|
|1|Ad-hoc|데이터 산재·정의 없음·직관 100%|
|2|Reactive|도구 일부·요청 응답·체계 ↓|
|3|Defined|표준·프로세스·자동화 일부|
|4|Managed|셀프 서비스·거버넌스·KPI|
|5|Optimized|데이터 의사결정 문화·AI·예측|

**데이터원더 현재**: **Level 2 (Reactive)·평균 2.3**

### 3.3 진단 방법 (4가지)

|방법|내용|대상|
|---|---|---|
|**인터뷰**|25명·1:1·45~60분|CEO·CPO·CTO·CDO + DA·DE·각 부서 리드·실무자|
|**설문**|60명·온라인·15분|데이터 사용자 (PM·마케팅·영업·CS 등)|
