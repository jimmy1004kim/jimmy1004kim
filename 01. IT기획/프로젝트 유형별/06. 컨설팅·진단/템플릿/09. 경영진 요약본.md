# T6-9. 경영진 요약본 (Executive Summary Brief)

## 이 문서는

최종 보고서 (T6-8) 의 **80~120 페이지 내용을 1~2 페이지로 응축하여 CEO·이사회·투자자 등 의사결정자가 단 5분 안에 핵심을 파악할 수 있게 만든 초압축 문서**.

T6 산출물 흐름에서의 위치:

```
[T6-8 최종 보고서·80~120p] ─┐
                              ├─ [T6-9 경영진 요약본] ⭐ ← 본 문서
[T6-10 발표 자료]            ─┘
        ↓
[CEO·이사회·투자자 의사결정]
```

### 경영진 요약본 vs 최종 보고서 Executive Summary

둘 다 "요약"이지만 **다른 문서**입니다:

|구분|T6-8 §1 Exec Summary|**T6-9 경영진 요약본**|
|---|---|---|
|위치|최종 보고서 안 (1~2p)|**독립 문서·별도 배포**|
|청중|보고서를 받은 사람|**보고서를 안 받은 의사결정자**|
|맥락|본문이 뒤에 있음|**이것만 봐도 결정 가능**|
|활용|보고서 도입|**이메일·이사회·투자자 배포**|
|분량|1~2p|**1~2p (PDF·인쇄)**|

### 경영진 요약본의 4대 역할

|역할|의미|
|---|---|
|**5분 안에 핵심 전달**|CEO·이사회 시간 가치|
|**독립적 의사결정 가능**|본문 없어도 결정|
|**확산 매체**|이사회·투자자·외부|
|**본문 진입 동기**|"이거만 봤는데 더 알고 싶다"|

### 5대 원칙

|원칙|의미|
|---|---|
|**1~2 페이지**|더 길면 의미 없음|
|**결정 지향**|"무엇을 해야 하는가" 명확|
|**정량 우선**|숫자·KPI·%|
|**시각화 풍부**|차트·다이어그램·아이콘|
|**독립적**|본문 참조 없이 이해 가능|

### 황금 구조 (1~2 페이지)

```
[Header — 5%]
- 제목·1줄 결론·작성일

[Section 1: 한 줄 진단 — 10%]
- 현재 상태 + 격차

[Section 2: 핵심 발견 (3~5개) — 25%]
- 정량 데이터 + 시사점

[Section 3: 핵심 권고 (3~5개) — 30%]
- 개선 방향 + 우선순위

[Section 4: 투자·ROI — 15%]
- 투자·회수·NPV·Payback

[Section 5: 의사결정 권고 — 10%]
- GO/NO-GO + 조건 + 다음 단계

[Footer — 5%]
- 본문 연결·문의처
```

### 작성의 5단계

|단계|활동|기간|
|---|---|---|
|1|**최종 보고서 (T6-8) 완성 후**|0일|
|2|**핵심 3~5 결정 사항 추출**|0.5일|
|3|**시각화 설계** (차트·다이어그램)|0.5일|
|4|**Draft + 다듬기**|1일|
|5|**CEO·외부 자문 검토**|0.5일|

총 **2~3일** 작성 (최종 보고서 작성과 병행 권장)

### 흔한 함정 (5가지)

|함정|증상|대응|
|---|---|---|
|**너무 김**|3~5 페이지|1~2 페이지 사수|
|**나열식**|발견 X개·결정 무|결정·권고 중심|
|**추상적**|"혁신·시너지"|정량·구체|
|**시각화 부족**|글자만|차트·다이어그램·아이콘|
|**본문 의존**|"상세는 보고서" 만|독립적 이해 가능|

### 청중별 강조점

|청중|강조|
|---|---|
|**CEO**|비전·전략·결정|
|**이사회**|ROI·리스크·시리즈 (다음 단계)|
|**CFO**|투자·NPV·Payback|
|**CTO**|기술 격차·로드맵 (요약)|
|**외부 투자자**|성장 스토리·데이터 운영 성숙도|

본 가이드 케이스에서는 **이사회·시리즈 C 투자자** 강조.

## 언제 만드나

- 최종 보고서 (T6-8) 완성 직후
- CEO 보고·이사회·투자자 미팅 직전
- 외부 배포 시

## 어떤 툴로

|툴|추천도|
|---|---|
|**Figma·Canva**|⭐ 강력 추천 (시각 디자인)|
|**PowerPoint·Keynote (2슬라이드)**|⭐ 추천|
|Microsoft Word|보조|
|노션 (Draft)|보조|

**최적**: Figma (디자인) → PDF 변환 (최종 배포 형식).

## 표준 구성

```
[1 페이지]
1. Header (제목·결론·일자)
2. 한 줄 진단
3. 5축 평가 시각화
4. 핵심 발견 3~5개
5. 핵심 권고 3~5개

[2 페이지]
6. 12개월 로드맵 (요약)
7. 투자·ROI
8. 위험 (Top 3)
9. 의사결정 권고·다음 단계
10. 본문 연결·문의처
```

## 들어가야 할 것

- 1줄 진단·결론
- 5축 시각화
- 핵심 발견 + 권고
- ROI 정량
- 로드맵 (1줄)
- 의사결정 권고

## 작성 절차

1. **T6-8 §1 Executive Summary 출발점**
2. **3~5개 결정 사항만** 추출
3. **시각화** 우선 설계
4. **1~2 페이지 사수**
5. **CEO 검토** 후 발효
