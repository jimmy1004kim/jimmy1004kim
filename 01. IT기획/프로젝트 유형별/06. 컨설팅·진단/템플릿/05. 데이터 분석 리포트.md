## 이 문서는

진단 대상 조직의 **운영·성과·고객·시장 데이터를 정량적으로 분석한 결과를 정리한 문서**.

AS-IS 분석 리포트가 인터뷰·관찰·평가 중심이라면, 데이터 분석 리포트는 **숫자로 말하는 객관적 진단**이다. "느낌상 매출이 줄었다" ❌ / "2024년 매출은 전년 대비 12% 감소, 영업이익률 8% → 5%" ⭕

이 문서는 AS-IS 분석 리포트의 **보조 자료**로 사용되거나, 데이터 비중이 큰 진단에서는 **독립 산출물**이 된다.

## AS-IS 분석 리포트와의 관계

| 구분     | AS-IS 분석 리포트   | 데이터 분석 리포트  |
| ------ | -------------- | ----------- |
| 주된 데이터 | 인터뷰·관찰 + 일부 정량 | 정량 데이터 100% |
| 분량     | 30~50p         | 10~25p      |
| 목적     | 종합 현황          | 정량 근거       |
| 활용     | 단독 산출물         | 보조 또는 독립    |

**활용 패턴**:

- 패턴 A: AS-IS 리포트의 부록 (정량 데이터를 별도 정리)
- 패턴 B: 독립 산출물 (성과 진단 등 데이터 중심 사업)
- 패턴 C: 인사이트 도출의 근거 자료 (다음 단계에서 활용)

## 언제 만드나

데이터 수집·분석 완료 후, AS-IS 분석 리포트 작성과 병행 또는 직후.

타임라인:

1. Phase 2: 데이터 수집
2. Phase 3 (병행):
    - AS-IS 분석 리포트
    - **데이터 분석 리포트** ← 여기
3. Phase 3: 문제 정의·인사이트
4. Phase 4: To-Be 권고

## 데이터 분석 4가지 유형

진단 사업에서 흔히 다루는 4가지 분석 유형.

### 1. 기술 통계 (Descriptive)

- "무엇이 일어났는가" — 평균·합계·증감률
- 가장 기본. 모든 진단에 포함

### 2. 진단 분석 (Diagnostic)

- "왜 그렇게 되었는가" — 원인·상관관계
- 두 변수 비교, 분포 분석

### 3. 예측 분석 (Predictive)

- "앞으로 어떻게 될 것인가" — 추세·예측
- 시계열 데이터로 미래 예측

### 4. 처방 분석 (Prescriptive)

- "어떻게 해야 하는가" — 권고·시뮬레이션
- 진단보다 To-Be 단계의 영역

**진단 사업의 데이터 분석 리포트는 주로 1·2번 (기술·진단)**, 일부 3번. 4번은 다음 단계로.

## 시각화 원칙 (5가지)

데이터 분석 리포트의 절반은 시각화. 잘못된 시각화는 잘못된 결론을 부른다.

### 1. 적절한 차트 선택

- 추이: 선 차트
- 구성: 막대·도넛
- 분포: 히스토그램
- 상관: 산점도
- 비교: 막대·레이더

### 2. 제목이 결론

"분기별 매출 추이" ❌ / "매출은 2022년 정점 후 3년 연속 하락" ⭕

### 3. 데이터-잉크 비율 최대화

불필요한 격자선·3D 효과·과장된 색상 제거

### 4. 색은 의미 있게

- 동일 종류 = 동일 색
- 강조할 것만 다른 색
- 보통 3색 이내

### 5. 출처·기간 명시

모든 차트에 데이터 출처·기준 시점

## 작성 팁

- **데이터 품질 먼저** — 분석 전에 데이터 완전성·정확성 점검. 신뢰 못 할 데이터로 분석하면 결론도 신뢰 못 함
- **모든 차트에 출처·기간** — 출처 없는 차트는 무근거 발언과 같음
- **차트 제목이 결론** — "월별 매출" ❌ / "매출은 3년 연속 하락 중" ⭕
- **사실과 해석 분리** — 차트는 사실, 해석은 별도 문단으로
- **상관 ≠ 인과** — "A와 B는 상관 0.9" ⭕ / "A가 B의 원인" ❌ (사실 단계에선 인과 결론 금지)
- **벤치마킹 데이터 확보** — 산업 평균 없으면 "잘함/못함" 판단 어려움
- **세그먼트 분석 잊지 말 것** — 평균만 보면 부서·제품별 격차 묻힘
- **수치 정확성 검토** — 차트의 숫자가 본문과 일치하는지 2회 검토
- **인사이트 vs 데이터 분리** — 데이터 분석 리포트는 사실. 인사이트는 다음 단계
- **분량 통제** — 10~25p 적정. 50p 넘으면 안 봄

## 자주 하는 실수

- **데이터 품질 점검 생략** — 신뢰 못 할 데이터로 분석 → 결론도 무용
- **추측을 사실로 표현** — "아마도 ~때문일 것이다" → 데이터 근거 없으면 빼기
- **인과 단정** — "A가 B의 원인" → 상관계수만으로 인과 단정 불가
- **불필요한 차트** — 표 하나로 충분한데 차트로 만들면 데이터-잉크 비율 악화
- **3D 차트·과장된 색** — 데이터 왜곡, 신뢰도 하락
- **출처 누락** — "어디서 가져왔는지 모를 데이터" → 신뢰 잃음
- **세그먼트 분석 누락** — 평균에 묻힌 인사이트 놓침
- **본문과 차트 수치 불일치** — 본문 5%, 차트 4.8% 같은 오차 → 신뢰 하락
- **너무 많은 지표** — 핵심 5~10개로 압축. 30개 나열은 노이즈
- **권고·해석 섞기** — "이를 개선해야 한다" → 다음 단계 (To-Be)로
