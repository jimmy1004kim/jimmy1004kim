## 이 문서는

컨설팅·진단 프로젝트의 **출발선이 되는 합의 문서**.

"이 진단으로 무엇을 풀 것이며, 어떤 방법으로, 누구를 대상으로, 무엇을 산출할 것인가"를 사전에 명확히 한다. 진단은 만들기보다 **분석·권고가 결과물**이므로, 시작 단계에서 범위가 모호하면 결과물이 모호해진다.

이 문서는 **고객과 합의되는 대외용**이다. 합의 후에는 변경 관리 절차로만 수정 가능.

## 다른 유형의 Charter와의 차이

|구분|일반 Project Charter|진단 계획서|
|---|---|---|
|결과물|시스템·서비스|보고서·권고안|
|핵심 합의|범위·일정·산출물|**진단 범위·방법론·산출물**|
|측정|정량 KPI (시간·비용 등)|정성·정량 혼합 (인사이트의 깊이)|
|종료|검수·납품|보고서 전달·발표|

기본 Charter 구조는 비슷하지만, **방법론·인터뷰 대상·진단 프레임워크**가 진단 계획서만의 핵심.

## 진단 방법론 (4가지 흔한 접근)

진단 계획서 작성 전에 어떤 방법론을 쓸지 결정.

### 1. 성숙도 모델 기반 (Maturity Model)

- 표준 모델(예: CMMI, COBIT, DX 성숙도)의 단계별로 현 위치 평가
- **언제**: 디지털 전환·IT 거버넌스 등 표준 모델 존재 영역
- **장점**: 객관적, 비교 가능
- **단점**: 모델이 본 조직에 안 맞을 수 있음

### 2. SWOT·5 Forces 등 전략 프레임워크

- 강·약·기회·위협 분석
- **언제**: 사업 전략 진단
- **장점**: 친숙·이해 용이
- **단점**: 정성적, 분석가 주관 개입 큼

### 3. 데이터 기반 진단

- KPI·사용자 행동 데이터·운영 데이터 정량 분석
- **언제**: 운영 중 서비스의 성과 진단
- **장점**: 객관성 최고
- **단점**: 데이터 부재 시 불가

### 4. 인터뷰·관찰 기반 (질적 연구)

- 다양한 계층 인터뷰, 현장 관찰
- **언제**: 조직·업무 프로세스 진단
- **장점**: 깊이 있는 인사이트
- **단점**: 표본 편향 가능

**대부분의 실무는 위 방법을 2~3개 조합 사용.**

## 1. 진단 배경·목적

### 1.1 진단 추진 배경

㈜OO제조는 자동차 부품 제조 중견기업(매출 800억, 임직원 250명)으로, 다음 환경에 직면해 있습니다.

- **고객사(완성차)의 디지털 협업 요구 증가** — EDI·MES 연동, 실시간 품질 데이터 공유 요구
- **세대 교체** — 60대 창업주가 40대 2세 경영자로 승계 중. 디지털 전환이 핵심 과제로 부상
- **경쟁사의 빠른 변화** — 동종 업체들이 스마트팩토리·ERP 고도화 진행 중
- **내부 인식 격차** — 경영진은 "변화 시급" vs 현장은 "지금도 잘 돌아간다"

본 진단은 **㈜OO제조의 현재 디지털 성숙도를 객관적으로 평가하고, 향후 3년 디지털 전환 로드맵의 기초를 제공**하기 위함입니다.

|본 진단의 목적|현 디지털 성숙도 진단 + 향후 3년 로드맵 권고안 도출|

### 1.3 진단의 기대 효과

- 객관적 성숙도 평가로 경영진·현장의 인식 격차 해소

## 작성 팁

- **Phase 1에 가장 신중하게** — 진단은 시작이 잘못되면 전체가 흔들림. 범위·방법론 합의에 시간 충분히
- **인터뷰 대상 균형** — 경영진만·실무자만 인터뷰하면 그림 왜곡. 계층·부서 다양하게
- **방법론 2~3개 조합** — 한 가지로만 진단하면 한계 명확. 양적·질적 혼합
- **고객 협조 사항 명확히** — 진단 실패의 절반은 고객 협조 부족. 미리 약속받기
- **익명성 보장 약속** — 인터뷰 대상자가 자유롭게 말하지 않으면 진단 가치 절반
- **권고안 실행 가능성** — 이상론적 권고는 무가치. Phase 4부터 실현 가능성 고려
- **중간 보고 = 신뢰 구축** — Phase별 중간 보고는 고객 신뢰 유지에 결정적
- **정치적 환경 사전 파악** — 컨설팅은 정치적 환경에 휘둘리기 쉬움. 사전 식별

## 자주 하는 실수

- **범위 모호하게 시작** — "전반적으로 진단" → 어디서 끝낼지 모름
- **방법론 단일** — 인터뷰만, 데이터만 등 한 가지로만 → 한계 명확
- **인터뷰 대상 편향** — 경영진·특정 부서만 → 그림 왜곡
- **고객 협조 사항 누락** — 자료 제공·인터뷰 조율 등 명시 안 함 → 진단 지연
- **익명성 약속 안 함** — 인터뷰 대상자 자기 검열 → 진단 가치 절반
- **권고안의 실행 가능성 무시** — 이상론적 권고 → "그럼 어떻게 하라고?"
- **정치적 환경 무시** — 진단 중간에 정치적 갈등 발생 → 객관성 훼손
- **중간 보고 생략** — 최종 보고에서 처음 보여줌 → 고객 충격·반발
- **벤치마킹 누락** — "그런데 다른 회사는?" 질문에 답 못 함
