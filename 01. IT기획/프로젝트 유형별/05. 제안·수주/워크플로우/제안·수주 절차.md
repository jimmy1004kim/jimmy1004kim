## 이 문서는

RFP 수령부터 수주 결정까지 **"무엇을, 언제, 어떤 순서로, 누가, 어떤 산출물로 진행하는가"의 표준 절차**.

제안 사업은 단기간(보통 2~4주)에 다수의 산출물을 동시에 만들어야 한다. 절차 없이 즉흥적으로 진행하면 산출물 일관성 깨지고, 마감 막판에 폭주한다. 이 워크플로우는 **그 혼란을 막는 가이드**다.

## 다른 문서와의 관계

| 문서                   | 역할                        |
| -------------------- | ------------------------- |
| **본 워크플로우**          | **시간 순서로 무엇을 할지 정리 (절차)** |
| 유형 5의 8개 템플릿         | 각 단계의 산출물 양식              |
| 공통 > 새 프로젝트 시작 워크플로우 | 수주 후 본격 진행 시작 시점          |

본 워크플로우는 **수주 직전까지**를 다루고, 수주 후의 본격 사업은 공통 워크플로우 + 유형 2(외주/구축) 워크플로우로 이어진다.

## 전체 흐름 한눈에

```
RFP 수령
   ↓
Phase 1. 분석·전략     (3~5일)
   - RFP 분석서
   - Go/No-Go 결정
   - Win Theme 정의서
   ↓
Phase 2. 본문 작성      (5~10일)
   - 범위 정의서
   - 견적서 (내부 산정)
   - 제안서
   - 사업수행계획서
   ↓
Phase 3. PT 준비       (3~5일)
   - 발표 자료
   - 예상 Q&A
   - 리허설
   ↓
Phase 4. 제출·발표     (1~2일)
   - 제안서 제출
   - PT 발표
   ↓
Phase 5. 사후         (1~2일)
   - 결과 대응
   - 제안 회고
   ↓
수주 → 본격 진행 (공통·유형 2 워크플로우로 이관)
실주 → 회고 자산화
```

총 13~24일 표준. 대형 사업은 더 길어질 수 있음.

## 어떤 툴로

본 워크플로우는 절차이므로 노션 페이지 + 체크리스트 형태가 적합.

|툴|추천도|이유|
|---|---|---|
|**노션**|⭐ 추천|체크리스트·하위 페이지·산출물 링크|
|구글 시트|보조|제안 트래커로 여러 RFP 동시 관리 시|

**팁**: 노션에 본 워크플로우 페이지를 복사해서 각 RFP마다 인스턴스 페이지를 만든다.

## 사용법

1. RFP 수령 시 본 워크플로우 페이지 복사
2. 해당 RFP 폴더 생성 후 그 안에 붙여넣기
3. 각 단계의 체크박스를 진행 상황에 맞춰 채워가며 진행
4. 단계별 산출물은 유형 5 템플릿에서 가져와 작성
5. 수주/실주 결정 후 회고 진행, 자산화

## 운영 팁

- **모든 단계는 병행 가능** — Phase 2의 범위·견적·제안서·사업수행계획서는 어느 정도 동시 진행이 일반적. 단, **RFP 분석·Win Theme이 먼저 확정**되어야 함
- **Win Theme 변경 시 알림** — Phase 2 진행 중 Win Theme 수정이 발생하면 모든 작성 중 산출물에 즉시 공지
- **버전 관리 엄격히** — v0.1 → v0.2 → v1.0 식으로 명확히. 최종 제출본은 v1.0
- **체크리스트는 진행 상태 추적용** — 빠뜨림 방지에 효과적
- **Go/No-Go는 객관적으로** — 영업 압박에 굴복해서 No-Go 못 내리면 적자 누적
- **회고는 수주·실주 모두** — 실주 회고가 더 가치 있을 때도 많음
- **자산화 빠뜨리지 말 것** — 회고만 하고 자산화 안 하면 다음 제안도 처음부터

## 자주 하는 실수

- **킥오프 생략** — 팀원별로 다른 그림 가진 채 작업 시작 → 산출물 일관성 깨짐
- **RFP 정독 안 하고 분석** — 부분만 보고 큰 그림 추정 → 핵심 누락
- **Go 결정 늦음** — 분석 후 결정 안 내리고 시간 끌면 본문 작업 시간 부족
- **Win Theme 없이 본문 시작** — 섹션별 메시지가 따로 놂
- **본문만 작성·PT 준비 미흡** — PT 50%가 당락 결정. 발표 자료·리허설 부족하면 본문 점수 다 잃음
- **리허설 1회로 끝** — 첫 리허설은 거의 시간 초과. 최소 2회
- **회고 없이 종료** — 실주 시 가장 큰 학습 기회를 놓침
- **자산화 미루기** — "나중에 정리할게"는 결국 안 정리됨. Phase 5에서 즉시
