# T4-7. 화면 정의서 (Admin Screen Specification)

## 이 문서는

내부 시스템의 **관리자·운영팀 화면을 디자인·개발이 구현 가능한 수준으로 명세한 문서**.

T4 산출물 흐름에서의 위치:

```
[T4-3 요구사항] + [T4-5 업무 흐름] + [T4-6 기능 정의] → [T4-7 화면 정의서] → 디자인·개발
```

T1·T3 화면 정의서와의 차이:

|구분|T1 화면 정의서 (신규)|T3 화면 변경 정의서 (개선)|**T4 화면 정의서 (Admin)**|
|---|---|---|---|
|사용자|외부 고객|외부 고객|**내부 직원 (운영팀)**|
|강조|사용자 경험·전환|Before·After|**업무 효율·정확성·작업 큐**|
|화면 수|적음 (핵심 페이지)|변경 부분|**많음 (모든 운영 화면 망라)**|
|시각 디자인|매우 중요|중요|**기능성 우선**|
|반응형|모바일 우선|둘 다|**PC + 태블릿 (모바일은 옵션)**|
|접근성|일반 사용자 기준|동일|**장시간 사용 운영팀 기준** ⭐|

**핵심**: Admin 화면은 **"운영팀이 하루 6~8시간 사용해도 효율적인가"**가 핵심. 시각 디자인보다 **정보 밀도·작업 큐·키보드 단축키·일괄 작업**이 중요.

### Admin 화면 설계의 7대 원칙

|원칙|의미|
|---|---|
|**작업 큐 우선**|"다음 할 일"이 명확히 보임|
|**정보 밀도**|한 화면에 많은 정보 (스크롤 ↓)|
|**일괄 작업**|Bulk 선택·일괄 처리|
|**키보드 단축키**|마우스 ↓|
|**상태 가시성**|상태·진행률 명확|
|**이상 강조**|알람·예외 즉시 식별|
|**반복 작업 최소화**|자동화 + 자동완성|

T4 화면 설계는 위 7대 원칙에 따라 평가.

### Admin 화면의 5가지 유형

|유형|의미|강조|
|---|---|---|
|**대시보드 (Dashboard)**|KPI·작업 큐·이상 알람|한눈에 파악|
|**목록·검색 (List)**|자원 목록·필터·검색|정보 밀도·일괄 작업|
|**상세·편집 (Detail)**|단일 자원 조회·편집|정확성·검증|
|**작업·처리 (Action)**|일괄 처리·자동화 트리거|명확성·되돌리기|
|**설정 (Settings)**|권한·정책·연동 설정|안전성·이력|

각 유형마다 설계 강조점이 다름.

### Admin 화면의 8가지 측면 (T3-7과 유사하나 강조점 다름)

|측면|내부 시스템 강조|
|---|---|
|**레이아웃**|정보 밀도 + 작업 큐|
|**인터랙션**|키보드 단축키 + 일괄|
|**시각 디자인**|기능성 + 상태 시각화|
|**콘텐츠**|정확한 데이터·라벨|
|**상태**|정상·로딩·빈·에러·진행 중|
|**반응형**|PC 1440px+ 최우선|
|**접근성**|장시간 사용·키보드|
|**권한별 UI**|역할별 다른 화면|
