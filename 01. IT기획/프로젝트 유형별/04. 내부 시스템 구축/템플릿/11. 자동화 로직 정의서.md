## 이 문서는

내부 시스템의 **자동화 동작·알고리즘·계산식·조건 분기를 개발 가능한 수준으로 명세한 문서**.

T4 산출물 흐름에서의 위치:

```
[T4-6 기능 정의] + [T4-8 정책] + [T4-9 데이터] + [T4-5 업무 흐름]
       ↓                ↓                ↓                ↓
       └────→ [T4-11 자동화 로직 정의서] → 구현 (코드)
                       ↓
            "어떻게 계산·실행·분기"
```

### 다른 산출물과의 관계

|산출물|자동화 관점|
|---|---|
|**T4-5 업무 흐름도**|자동화가 업무 흐름에서 차지하는 위치 (사람 vs 시스템 분담)|
|**T4-6 기능 정의**|자동화 기능의 명세 (입출력·SLA·수용 기준)|
|**T4-8 정책**|자동화가 따라야 할 비즈니스 규칙|
|**T4-9 데이터**|자동화가 사용·생성하는 데이터|
|**T4-11 자동화 로직 (본 문서)**|**알고리즘·계산식·조건 분기 상세**|

**핵심**: T4-11은 **"어떻게 계산·실행·분기"**의 상세. 개발자가 코드로 옮길 수 있는 수준의 명세.

### 왜 자동화 로직 정의서가 별도 필요한가

T4-6 기능 정의서에 다 적으면 안 되는 이유:

- **알고리즘이 비즈니스 규칙** — 개발팀만 보면 안 됨·운영팀·법무·재무 검토 필요
- **변경 가능성** — 가중치·임계치는 운영 중에도 자주 변경
- **테스트 케이스 도출** — 자동화 로직 = QA 시나리오 직결
- **재현 가능성** — 결과 검증·재현·롤백
- **알고리즘 자체가 자산** — 노하우의 시스템화

#### D. 알고리즘 (의사 코드)

```pseudo
function sync_stock_to_channels(event):
    # 1. 입력 검증 + idempotency
    if event_already_processed(event.event_id):
        return SKIP  # 중복 방지

    sku_id = event.payload.sku_id

    # 2. OpsHub 기준 재고 계산 (current ± delta)
    current_stock = get_opshub_stock(sku_id)
    new_stock = max(0, current_stock + event.payload.delta)  # POL-012 음수 금지

    if current_stock + event.payload.delta < 0:
        send_alert("재고 음수 시도 — 0으로 클램프", WARNING)

    # 3. OpsHub DB 업데이트 (트랜잭션)
    update_opshub_stock(sku_id, new_stock)

    # 4. 9개 채널 병렬 동기화 (asyncio)
    channels = get_active_channels()  # 9개
    sync_tasks = [
        sync_channel(channel, sku_id, new_stock)
        for channel in channels
    ]

    # timeout 30초 (각 채널), 병렬 실행
    results = await asyncio.gather(*sync_tasks, return_exceptions=True)

    # 5. 결과 분류
    success_channels = []
    failed_channels = []
    for channel, result in zip(channels, results):
        if isinstance(result, Exception) or not result.success:
            failed_channels.append({
                "channel": channel.code,
                "error": str(result),
                "error_code": result.error_code if hasattr(result, "error_code") else "UNKNOWN"
            })
        else:
            success_channels.append(channel.code)

    # 6. 결과 분기
    if len(failed_channels) == 0:
        # 모두 성공
        record_sync_history(sku_id, new_stock, "SUCCESS", success_channels, [])
        publish_event("stock.synced", {sku_id, new_stock, channels: success_channels})
        # 5분 후 정합성 검증 트리거 (AUTO-005)
        schedule_consistency_check(sku_id, after_seconds=300)
    else:
        # 일부 실패 → 자동 재시도 (AUTO-015)
        retry_result = await auto_retry(
            failed_channels=failed_channels,
            max_retries=3,
            backoff="exponential",  # 5·15·45초
            sku_id=sku_id,
            new_stock=new_stock
        )

        if retry_result.all_success:
            record_sync_history(sku_id, new_stock, "SUCCESS_WITH_RETRY", success_channels + retry_result.success, [])
            publish_event("stock.synced", ...)
            schedule_consistency_check(sku_id, after_seconds=300)
        else:
            # 최종 실패
            record_sync_history(sku_id, new_stock, "PARTIAL_FAIL",
                              success_channels + retry_result.success,
                              retry_result.failed)
            publish_event("stock.sync_failed", {
                sku_id,
                failed_channels: retry_result.failed
            })
            # 슬랙 알람·운영팀 수동 보정 트리거 (F-014)
            send_alert("재고 동기화 실패 (재시도 후)", HIGH, {sku_id, failed_channels: retry_result.failed})
```

```pseudo
    # 5. 큰 규모 익명화는 운영팀장에게 보고
    if len(candidates_filtered) > 100:
        notify("대량 익명화 처리됨", count=len(candidates_filtered))
```

#### A. 메타

#### B. 목적·트리거

- **목적**: 외부 API 호출 실패 시 자동 재시도 (일시 장애·Rate Limit 대응)
- **트리거**: 모든 외부 API 호출 실패 시
- **빈도**: 즉시 (필요 시)

#### C. 입력·출력

**입력**:

```python
{
  "operation": callable,  # 재시도할 작업
  "max_retries": 3,
  "backoff_seconds": [5, 15, 45],  # 시도별 대기
  "retry_on": [500, 502, 503, 504, "timeout", 429]  # 재시도 대상 에러
}
```

**출력**: 성공·실패

#### D. 알고리즘

```pseudo
function auto_retry(operation, max_retries=3, backoff=[5,15,45], retry_on=[500,502,503,504,"timeout",429]):
    last_error = None

    for attempt in range(max_retries):
        try:
            result = await operation()
            if result.success:
                log_info(f"성공 (시도 {attempt + 1})")
                return SUCCESS, result
        except Exception as e:
            last_error = e

            # 재시도 대상 에러인지 확인
            if not is_retryable(e, retry_on):
                # 재시도 안 함 (4xx 등 비재시도 에러)
                log_error("재시도 불가 에러", e)
                return FAIL, e

            log_warn(f"실패 (시도 {attempt + 1}/{max_retries})", e)

        # 마지막 시도가 아니면 대기 후 재시도
        if attempt < max_retries - 1:
            wait_time = backoff[attempt]
            log_info(f"{wait_time}초 대기 후 재시도")
            await asyncio.sleep(wait_time)

    # 모든 시도 실패
    log_error(f"모든 재시도 실패 ({max_retries}회)", last_error)
    return FAIL, last_error

function is_retryable(error, retry_on):
    if isinstance(error, TimeoutError) and "timeout" in retry_on:
        return True
    if hasattr(error, "status_code") and error.status_code in retry_on:
        return True
    return False
```
