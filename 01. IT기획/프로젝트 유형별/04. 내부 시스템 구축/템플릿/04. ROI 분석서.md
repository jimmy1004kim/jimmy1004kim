# T4-4. ROI 분석서 (Return on Investment Analysis)

## 이 문서는

내부 시스템 구축의 **투자 비용 vs 회수 가치를 정량 분석한 의사결정 근거 문서**.

T4 산출물 흐름에서의 위치:

```
[T4-1 AS-IS] + [T4-2 TO-BE] + [T4-3 요구사항] → [T4-4 ROI 분석] → 의사결정 GO/NO-GO
                                                      ↓
                                          "투자 대비 가치 있나"
```

다른 산출물과의 비교:

|구분|T4-2 TO-BE|T4-3 요구사항|**T4-4 ROI 분석**|
|---|---|---|---|
|목적|청사진|명세|**투자 정당화**|
|청중|전체 팀|개발·QA|**의사결정자 (CEO·CFO·CTO)**|
|강조|미래 비전|무엇을 만들까|**돈으로 환산**|
|시점|전략·설계|명세 단계|**GO/NO-GO 결정**|

**핵심**: 내부 시스템 구축의 가장 큰 실패 원인 중 하나가 **"투자 대비 가치 입증 못 함"**. ROI 분석이 의사결정자 설득의 핵심 무기.

### ROI 분석의 5가지 책임

1. **투자 비용 정량화** — 인건비·인프라·외주·기회비용 모두
2. **회수 가치 정량화** — 시간 절감·에러 감소·매출 증가 모두
3. **회수 기간 (Payback Period) 산출** — 언제 본전 회수
4. **순현재가치 (NPV)·IRR** — 장기 가치 평가
5. **리스크·민감도 분석** — 가정·시나리오별 변동

### 정량화의 4가지 영역

|영역|측정 가능성|예시|
|---|---|---|
|**직접 비용 절감**|高 (정량)|인건비·외부 도구 라이선스|
|**간접 비용 절감**|中 (추정)|휴먼 에러 손실·기회비용|
|**매출 증가**|中 (추정)|채널 확장·고객 만족도|
|**무형 가치**|低 (정성)|직원 만족·브랜드·민첩성|

본 가이드는 **4가지 모두 다루되, 정량 가능한 것 (직접·간접) 중심 + 무형은 보조**.

### ROI 계산 4가지 방식

|방식|공식|적용|
|---|---|---|
|**단순 ROI**|(이익 - 비용) / 비용 × 100%|빠른 평가|
|**회수 기간 (Payback)**|초기 투자 / 연간 절감|"언제 본전"|
|**순현재가치 (NPV)**|Σ (연도별 현금흐름 / (1+r)^n) - 초기 투자|**장기 정량 평가** ⭐|
|**내부수익률 (IRR)**|NPV=0 만족하는 r|대안 비교|

본 가이드는 **단순 ROI + Payback + NPV** 3가지 권장.

### ROI 함정 (5가지)

|함정|증상|대응|
|---|---|---|
|**과대 추정**|"운영팀 시간 100% 절감"|보수적 추정 (50~70%)|
|**비용 누락**|인건비만, 기회비용·운영비 누락|5년 TCO 포함|
|**무형 가치 과의존**|"민첩성·만족도"만 강조|정량 70% + 정성 30%|
|**단년도만**|1년 ROI만 봄|3~5년 NPV|
|**민감도 무시**|가정 100% 달성 전제|비관·현실·낙관 시나리오|

본 가이드는 함정 5가지 모두 회피.

### 3.1 단순 ROI (5년)

```
ROI = (8.26 / 4.14) × 100% = 약 199%
```

(참고: ROI를 "투자 회수의 배수"로 계산하면 보수적 회수 가치 / 초기 투자 1.375억 ≈ **824%**)

### 3.2 회수 기간 (Payback Period)

```
초기 투자 (Y1): 1.375억원
Y2 연 회수 가치 (보수적): 2.50억원 (Y2 보정)

Payback = 1.375 / (2.50 / 12) = 약 6.6개월 (Y2 기준)
또는 Y1 누적 (구축 기간 0.77억원 회수) → 잔여 0.605억원 / Y2 월 0.21억 = 약 3개월 추가
총 Payback = Y1 12개월 + Y2 약 3개월 추가 = **약 15개월** (현실 보정)

낙관 시나리오: **11개월** (Y2 진입 직후 회수 완료)
보수적 (비관): **18개월**
```

- **가정·한계 명시** — 100% 달성 전제 X
- **사후 측정 계획** — Realized ROI로 검증
- **경영진 친화 표현** — "투자 1.2억으로 11억 추가 가치" 같은 한 줄
- **단가·비율 출처 명시** — 시간당 인건비·할인율 등
- **CFO 검토 필수** — 재무 관점 점검

## 자주 하는 실수

- **단년도만 봄** — 1년 ROI만 → 장기 가치 누락
- **인건비만 봄** — 운영비·기회비용 누락
- **회수 가치 과대 추정** — "100% 절감" → 비관 시나리오 누락
- **NPV 안 봄** — 단순 ROI만 → 시간 가치 무시
- **Payback 누락** — "언제 본전" 답 없음 → 의사결정자 불안
- **시나리오 없음** — 단일 추정 → 리스크 인지 X
- **민감도 분석 없음** — 어떤 변수가 핵심인지 모름
- **Do Nothing 비교 없음** — "안 만들면 어떻게 되나" 답 없음
- **무형만 강조** — "민첩성·만족도"만 → 의사결정자 설득 X
- **가정 명시 X** — 100% 달성 전제 → 사후 책임 모호
- **사후 측정 계획 없음** — Realized ROI 검증 X
- **CFO 검토 안 받음** — 재무 관점 누락
- **출처·단가 모호** — "시간당 X원" 근거 없음
